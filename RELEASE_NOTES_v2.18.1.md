# Reticula 2.18.1 (quick fix)

**Release date:** 2026-11-19

## Downloads

- Windows 10/11: `Reticula_Setup_2.18.1.exe` (not code-signed - SmartScreen: *More info* → *Run anyway*)
- macOS, Apple Silicon: `Reticula_2.18.1_macOS_arm64.dmg` (not notarised - first start: right-click → *Open*; see `README_macOS.txt`)
- `SHA256SUMS.txt` to verify the downloads.

## What changed

- The module **Schemes & Icons** is now called **Reticon**.
- The icon library in the Reticon editor can be widened (drag the edge; double-click resets); wider means more icons per row.
- **Full screen** in the Reticon editor (button or Ctrl+Shift+M): the editor fills the window, with larger labels and buttons.

Full list: `app/CHANGELOG.md`.
