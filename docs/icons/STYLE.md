# Icon style guide (Reticula, 2.19.0)

Scientific, restrained, for figures meant for publication. Not playful.

- Grid: 24 x 24 units for navigation icons; 60 x 60 units for Reticon library icons.
- Stroke: one line weight per icon. 1.5 units on the 24 grid (about 0.06 of the icon size). Round caps and joins.
- Palette (fixed):
  - ink `#1F2D3D` for outlines and text-like marks;
  - accent `#2E6F95` (steel blue) for the one element the icon is about;
  - muted `#8FA3B5` for secondary parts (axes, supports, background bonds);
  - paper `#FFFFFF` fill for solids. Nothing else.
- No gradients, no glossy highlights, no drop shadows, no sunburst or starburst shapes, no emoji-like forms.
- One accent element at most per icon. Labels are not used inside icons.
- Every icon renders to PNG and passes the tests before it is added.
