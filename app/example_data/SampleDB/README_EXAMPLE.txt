EXAMPLE DATA - synthetic sample list for the Sample database page (not real samples).

Your own list: any Excel file whose first sheet has a header row with a "Sample ID" column. Optional columns:
  Name, Paper (or Project), Protocol family, Parent / starting material, Protocol basis, Main source (DOI),
  Protocol (docx), Protocol (PDF), Paper matrix
Protocol files are looked up next to the workbook in Paper<N>/Protocols/ (N = the number in the Paper/Project column).
Data files are linked to a sample when their name contains the sample ID, e.g. EX-M801-F25-B1_PXRD.xy (B1 = batch 1).
