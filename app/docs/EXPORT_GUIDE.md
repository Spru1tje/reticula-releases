# Which file to export from each instrument

Menu names differ slightly between software versions; if a menu item is not where it is described, look for the
equivalent *Export / Save as ASCII / Data point table* command. When in doubt, **any two-column text file** (x, y)
works for spectra and patterns, with comma, semicolon or tab as separator and either decimal point or decimal comma.

| Technique (instrument the export was tested with) | Best file to give the app | Natively read? | How to get it |
|---|---|---|---|
| ¹H NMR – Bruker Avance 400 (TopSpin) | **zip of the experiment folder** (e.g. `10/` with `acqus`, `pdata/1/1r`, `pdata/1/procs`) | yes (nmrglue + procs OFFSET/SW_p/SF) | Process (ft, phase, baseline, reference TMSP-d4 = 0 ppm) in TopSpin, then zip the numbered experiment folder. Alternative: type `totxt` in TopSpin → text file with `# LEFT = … ppm. RIGHT = … ppm.` header. |
| PXRD – STOE STADI P Combi (WinXPOW) | `.xy` / `.dat` ASCII (2θ, counts [, esd]) | text yes; binary `.raw` only with optional `xylib` | WinXPOW *Raw Data Handling* → File → Export (or "Save as ASCII / XY"). Keep Cu Kα1 2θ. |
| ATR-FTIR / FT-Raman – Bruker Vertex 70 + RAM II (OPUS) | OPUS file (`*.0`, `*.1`, …) or `.dpt` | yes (brukeropusreader: AB/ScSm/TR/Raman blocks) | OPUS: File → Save As → *Data Point Table* (.dpt) if the binary cannot be read. |
| Photoluminescence – any spectrofluorometer (Horiba FluoroMax / Fluorolog, Edinburgh FLS, Hitachi, Ocean Optics …) | `.csv` / `.txt` / `.dat` / `.xlsx`: two columns (wavelength nm, intensity) per file, or one table with the wavelength in column 1 and one column per temperature | yes | Export / save the corrected spectrum as ASCII or Excel. For temperature series either write the temperature in the column header (`293.15 K`, `25 °C`) or in the file name (`sample_300K.txt`); it can be edited in the app. Photon counts (not normalised) are needed for the temperature uncertainty σT. |
| SEM – Philips XL30 FEG | original `.tif` | yes (tifffile; FEI `[Scan] PixelWidth`, Zeiss tag, magnification) | Save the image as TIFF with the databar. If the pixel size is not in the metadata, enter it (or derive it from the databar marker: pixel size = marker length / marker pixels). XL30 magnification is referenced to a 127 mm wide display – the app shows the corresponding nm/px as a cross-check only. |
| TEM (any Gatan/FEI/Thermo microscope) | original `.dm3`/`.dm4` (Digital Micrograph), `.ser`/`.emd` (TIA/Velox), `.mrc`; otherwise TIFF/PNG | yes (ncempy; pixel size and unit read from the file) | Save the raw file from Digital Micrograph/Velox – don't export a screenshot. For TIFF/PNG without calibration, enter nm/px manually (or use an ImageJ-calibrated TIFF: *Analyze → Set Scale*, then *Save As → Tiff*; the app reads the ImageJ unit + resolution). |
| EDX maps | one greyscale PNG/TIFF per element | yes | In the EDX software (e.g. EDAX Genesis/TEAM, Oxford AZtec) export each element map as a greyscale image. Name files `…_Hf.png`, `…_Zr.png`, `…_S.png`. |
| ICP-OES – PerkinElmer Optima 8300 (Syngistix) | Syngistix CSV (one row per sample × analyte) | yes | Syngistix *Data Manager* → select results → Export → CSV (Sample ID, Analyte Name, Conc (Calib/Samp), Units, SD, %RSD). Enter digested mass and volume in the app to convert mg/L → wt%. |
| N₂ sorption – Micromeritics 3Flex (MicroActive) | Excel export of the report (`.xls/.xlsx`). The **full report** (Summary, Isotherm Tabular, BET, Langmuir, t-plot, linear/log plot overlays, DFT) is fine | yes. v2 finds every table in the sheet(s), uses only the **Isotherm Tabular** table (falls back to the plot overlay tables if absent), splits adsorption/desorption in measurement order, converts mmol/g → cm³/g STP, and reads the reported BET/Langmuir/t-plot values for reference | MicroActive: open the sample file → Reports → select *Isotherm Tabular* and *DFT* → Export to Excel. Binary `.SMP/.QPS` files are not read. |
| TGA (vendor unknown) | ASCII/CSV with temperature and mass (mg or %) | yes: Netzsch Proteus ASCII (`##Temp./°C;Time/min;Mass/%`), TA Universal Analysis text (`StartOfData`), Mettler STARe export, generic CSV | Netzsch Proteus: Extras → Export data → ASCII. TA Universal Analysis: File → Export Data File → Signals only; TRIOS: Export → CSV. Mettler STARe: export the curve as ASCII/Other. Measure **in air** (end product MO₂) for the defect calculator. |
| SDS-PAGE – Bio-Rad Gel Doc EZ (Image Lab) | *Lane and Bands* analysis table as CSV/Excel | yes (Lane, Band No., Band Label, Mol. Wt., Adj. Volume, Band %, Lane %) | Image Lab: Analysis Table → *Lane and Bands* → Export analysis table to spreadsheet/CSV. Add a time column, or map lanes → time in the app. |
| Zeta potential / DLS – Malvern Zetasizer | CSV export | yes (Sample Name, Z-Ave (d.nm), PdI, Zeta Potential (mV), Zeta Deviation, Sizes[n]/Intensities[n]) | Zetasizer software: select records → File → Export → choose parameters → CSV (ZS Xplorer: Export → CSV). Measure at the hydrolysis pD, not in phosphate buffer. |
| XPS | region exported as CSV/TXT (BE, counts) | yes; simple VAMAS `.vms` | CasaXPS or Thermo Avantage export of the region as ASCII/CSV, charge-corrected (C 1s = 284.8 eV). |
| Gly-Gly kinetics (¹H NMR) | table: sample, time, concentration (or integrals + TMSP integral) | yes | Integrate in TopSpin (Gly-Gly 3.80/3.88 ppm, 4H; TMSP-d4 0.00 ppm, 9H) and collect in Excel; replicates as extra rows. |
| Adsorption isotherm | table: sample, Ce, qe | yes | From the ¹H NMR supernatant concentrations. |
| Potentiometric titration (defect calculator) | table: V(NaOH) (mL), pH | yes | Autotitrator export (e.g. Metrohm tiamo, Mettler LabX) of the measured points as CSV. |
