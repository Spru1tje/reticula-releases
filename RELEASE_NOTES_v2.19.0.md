# Reticula 2.19.0

## Reticon library
- 300 new material-science icons, five shape variants each (1500 variants). The library now holds 1354 icons.
- New scientific palette and line style for the Reticon renderer and the navigation icons (see `docs/icons/STYLE.md`).
- Limitation: the new icons are schematic; several terms share a drawing. Check them against the source before publication.

## Workflow
- Routines do not overlap: a new run stops if another run is still active.

## Checks
- Element counts for the hand-built icons; every new variant renders to PNG.
