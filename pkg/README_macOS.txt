Reticula for macOS (Apple Silicon)
Publication figures for framework materials
============================================

INSTALL
1. Open the .dmg and drag Reticula to Applications.
2. The app is not notarised by Apple. The first time, right-click Reticula -> Open -> Open
   (or System Settings -> Privacy & Security -> "Open Anyway").
   If macOS says the app is damaged, run once in Terminal:   xattr -cr /Applications/Reticula.app

START
- Open Reticula. A small window appears and your browser opens at http://127.0.0.1:8501.
- The first start can take up to a minute.
- Everything runs on your own Mac; nothing is uploaded.

YOUR FILES
- ~/Library/Application Support/Reticula holds saved work, the sample database, settings and logs.
- Exports are written to ~/Library/Application Support/Reticula/exports (button "Open exports" in the window).

Intel Macs: there is no Intel build; use "Run from source" (README on GitHub).
